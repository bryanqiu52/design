使用说明

  1. 在「案例管理」中添加或修改案例
  2. 在「个人信息」中更新网站基本信息和关于页面内容
  3. 点击「导出所有修改」或切换到「代码导出」查看生成的代码
  4. 复制代码或下载文件，替换项目中的对应文件
  5. 将修改后的文件上传到 GitHub 仓库
  6. GitHub Actions 会自动部署更新
